📝 CAMBIO TÉCNICO:
   ───────────────

   ANTES (STATIC - NO FUNCIONABA):
   ════════════════════════════════

   ```dart
   BodyDef()
     ..type = BodyType.static  // ❌ Completamente inmóvil
   ```

   PROBLEMA:
   • No interactúan con objetos dinámicos
   • Enemigos caen a través o flotan
   • Colisiones limitadas

   ───────────────────────────────────────────

   AHORA (SLEEPING - FUNCIONA):
   ════════════════════════════

   ```dart
   BodyDef()
     ..type = BodyType.dynamic  // ✅ Dinámico pero dormido
     ..fixedRotation = isStatic // ✅ Evita rotación excesiva
   
   onLoad() {
     if (isStatic) {
       body.setAwake(false);  // ✅ Ponerlo a DORMIR
       _awake = false;
     }
   }
   
   beginContact() {
     if (isStatic && !_awake) {
       if (velocidad > 3) {
         body.setAwake(true);  // ✅ DESPERTAR
         _awake = true;
       }
     }
   }
   
   update() {
     // Mantener dormidos mientras no haya impacto
     if (isStatic && !_awake) {
       body.setAwake(false);
     }
   }
   ```

🔬 ESTADOS DEL BLOQUE:
   ────────────────────

   ESTADO 1: DORMIDO (SLEEPING)
   ═════════════════════════════
   • isStatic = true
   • _awake = false
   • body.setAwake(false)
   
   COMPORTAMIENTO:
   • NO reacciona a gravedad
   • SÍ permite colisiones
   • SÍ soporta otros objetos
   • Permanece en su lugar
   • ✅ Enemigos pueden estar encima

   ───────────────────────────────────────────

   ESTADO 2: DESPIERTO (AWAKE)
   ════════════════════════════
   • _awake = true
   • body.setAwake(true)
   
   COMPORTAMIENTO:
   • Reacciona a gravedad
   • Física completamente activa
   • Cae, rota, colisiona
   • Comportamiento normal

═══════════════════════════════════════════════════════════════════════

⚡ ACTIVACIÓN DEL BLOQUE:
   ──────────────────────

   UMBRAL: velocidad > 3

   CONDICIONES:
   1. El bloque debe estar marcado como isStatic
   2. El bloque debe estar dormido (_awake = false)
   3. Debe recibir una colisión
   4. La velocidad relativa debe ser > 3

   EJEMPLOS:
   • Alien disparado: velocity = 30-50  ✅ SE DESPIERTA
   • Bloque cayendo:  velocity = 10-20  ✅ SE DESPIERTA
   • Enemigo cayendo: velocity = 5-10   ✅ SE DESPIERTA
   • Toque suave:     velocity = 1-2    ❌ SIGUE DORMIDO

🔄 CICLO DE VIDA:
   ──────────────

   1. CREACIÓN:
      Brick(isStatic: true)
      └─> body.type = dynamic

   2. INICIALIZACIÓN (onLoad):
      body.setAwake(false)
      └─> _awake = false
      └─> Bloque DORMIDO 😴

   3. MANTENIMIENTO (update):
      if (!_awake)
        body.setAwake(false)
      └─> Mantiene dormido

   4. COLISIÓN (beginContact):
      if (velocidad > 3)
        body.setAwake(true)
        └─> _awake = true
        └─> Bloque DESPIERTO 😃

   5. FÍSICA ACTIVA:
      Cae, rota, colisiona
      └─> Comportamiento normal
