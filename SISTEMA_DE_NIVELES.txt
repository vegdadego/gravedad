3. 🏀 REBOTE DEL ALIEN EN LOS BORDES
   ────────────────────────────────────

   ✅ El alien REBOTA en lugar de desaparecer
   ✅ Rebote en borde derecho
   ✅ Rebote en borde izquierdo
   ✅ Velocidad reducida al 70% en cada rebote
   ✅ Solo desaparece si cae muy abajo

   CÓDIGO:
   ```dart
   // Rebote en borde derecho
   if (position.x > borde_derecho) {
     position.x = borde_derecho;
     velocidad.x *= -0.7;  // Invierte y reduce
   }
   
   // Rebote en borde izquierdo
   if (position.x < borde_izquierdo) {
     position.x = borde_izquierdo;
     velocidad.x *= 0.7;  // Invierte y reduce
   }
   ```

   VENTAJAS:
   • Más oportunidades de golpear
   • Más realista físicamente
   • Estrategias de rebote posibles
   • Menos frustrante

      • Elimina todos los enemigos
      • Usa tus disparos sabiamente

      • Vuelve al menú para otro nivel
