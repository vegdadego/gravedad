📳 2. SCREEN SHAKE (Vibración)
   ───────────────────────────

   CUÁNDO SE ACTIVA:
   • Al disparar el alien: intensidad 0.2
   • Al eliminar enemigo: intensidad 0.3
   • Impactos grandes: intensidad variable

   CARACTERÍSTICAS:
   • Vibración suave y realista
   • Desvanecimiento gradual (2s)
   • No interfiere con el gameplay
   • Acumulable (impactos múltiples)

   IMPLEMENTACIÓN:
   ```dart
   void addScreenShake({double intensity = 0.5}) {
     _shakeIntensity = (_shakeIntensity + intensity).clamp(0, 1.0);
   }
   
   update(dt) {
     if (_shakeIntensity > 0) {
       camera.viewfinder.position = Vector2(
         random * _shakeIntensity,
         random * _shakeIntensity
       );
     }
   }
   ```

🏆 4. SISTEMA DE PUNTUACIÓN
   ─────────────────────────

   PUNTOS POR ACCIÓN:
   ━━━━━━━━━━━━━━━━━━
   • Enemigo eliminado:  +100 pts
   • Bloque destruido:   +10 pts
   • Bonus perfecto:     +500 pts (≤30% disparos)
   • Bonus eficiente:    +300 pts (≤50% disparos)

   SISTEMA DE ESTRELLAS:
   ━━━━━━━━━━━━━━━━━━━━
   ⭐⭐⭐ (3 estrellas) = Usar ≤30% de disparos
   ⭐⭐   (2 estrellas) = Usar ≤50% de disparos
   ⭐     (1 estrella)  = Completar nivel

   EJEMPLOS:
   Nivel con 10 disparos:
   • Usar 1-3 disparos = ⭐⭐⭐ + 500 pts bonus
   • Usar 4-5 disparos = ⭐⭐ + 300 pts bonus
   • Usar 6-10 disparos = ⭐

   TRACKING:
   • Enemigos eliminados
   • Bloques destruidos
   • Puntuación total
   • Eficiencia de disparos
