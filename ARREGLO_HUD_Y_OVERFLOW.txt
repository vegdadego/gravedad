🔴 PROBLEMA 1: CONTADOR DE DISPAROS NO VISIBLE
   ────────────────────────────────────────────

   CAUSA:
   • Posición incorrecta (coordenadas del mundo)
   • Fuera del área visible de la cámara
   • Anchor incorrecto

   ANTES:
   ```dart
   anchor: Anchor.bottomLeft,
   position: Vector2(
     -camera.visibleWorldRect.width / 2 + 10,  // Muy a la izquierda
     camera.visibleWorldRect.height / 2 - 10,  // Muy abajo
   )
   world.add(_shotsCounter!)  // En el mundo (se mueve)
   ```

   AHORA:
   ```dart
   anchor: Anchor.topLeft,
   position: Vector2(10, 10),  // Superior izquierda simple
   camera.viewport.add(_shotsCounter!)  // En viewport (fijo)
   ```

   RESULTADO:
   ✅ Contador siempre visible
   ✅ Posición fija en pantalla
   ✅ No se mueve con el mundo

🔴 PROBLEMA 2: OVERFLOW EN PANTALLA DE VICTORIA
   ─────────────────────────────────────────────

   CAUSA:
   • Elementos muy grandes (fontSize: 48)
   • Padding excesivo (40px)
   • Sin límite de ancho
   • No se adaptaba a pantallas pequeñas

   ANTES:
   ```dart
   Container(
     padding: EdgeInsets.all(40),  // Muy grande
     child: Column(
       children: [
         Text(fontSize: 48),  // Muy grande
         Icon(size: 50),      // Muy grande
         ...
       ]
     )
   )
   ```

   AHORA:
   ```dart
   Container(
     constraints: BoxConstraints(maxWidth: 500),  // Límite de ancho
     margin: EdgeInsets.all(20),   // Margen externo
     padding: EdgeInsets.all(30),  // Padding reducido
     child: Column(
       children: [
         Text(fontSize: 36),  // Tamaño reducido
         Icon(size: 40),      // Tamaño reducido
         ...
       ]
     )
   )
   ```

   RESULTADO:
   ✅ No overflow
   ✅ Se adapta a pantallas pequeñas
   ✅ Contenido completo visible
   ✅ Diseño responsive
