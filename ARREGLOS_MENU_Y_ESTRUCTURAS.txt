3. 📐 ESTRUCTURAS REDISEÑADAS
   ────────────────────────────

   NIVEL 1 - TORRE SIMPLE:
   ═══════════════════════

        [==madera==]  ← Techo
            |  |
        [vidrio] [vidrio]  ← Columnas
            |  |
          👾    👾  ← Enemigos dentro
            |  |
        [==madera==]  ← Base

   CARACTERÍSTICAS:
   • Base horizontal grande (220x70)
   • 2 columnas de vidrio verticales (70x140)
   • Techo horizontal (220x70)
   • 2 enemigos protegidos dentro
   • Fácil de derribar atacando columnas

   ───────────────────────────────────────────

   NIVEL 2 - PIRÁMIDE:
   ═══════════════════

         [=madera=]  ← Techo
             |
      [vidrio] [vidrio]  ← Columnas
          |  👾  |  ← Enemigos dentro
   [madera][piedra][madera]  ← Base

   CARACTERÍSTICAS:
   • Base de 3 bloques horizontales
   • Centro de piedra más resistente
   • 2 columnas verticales de vidrio
   • Techo pequeño de madera
   • 2 enemigos en el centro
   • Estructura piramidal clásica

   ───────────────────────────────────────────

   NIVEL 3 - FORTALEZA:
   ════════════════════

     [========metal========]  ← Techo fortificado
         |             |
      [vidrio]      [vidrio]  ← Columnas centrales
         |   👾👾👾    |      ← 3 enemigos
   [madera]==puente==[madera]
         |             |
   [piedra]         [piedra]  ← Torres laterales
   [piedra]         [piedra]

   CARACTERÍSTICAS:
   • 2 torres laterales de piedra (resistentes)
   • Puente central de madera
   • Columnas de vidrio en el centro
   • Techo de metal (muy resistente)
   • 3 enemigos distribuidos
   • Estructura compleja de fortaleza

═══════════════════════════════════════════════════════════════════════

4. 🎯 POSICIONAMIENTO DE ENEMIGOS
   ────────────────────────────────

   ANTES:
   • Enemigos en posiciones aleatorias
   • Podían estar fuera de estructuras
   • Sin relación con los bloques

   AHORA:
   • Nivel 1: 2 enemigos dentro de la caja
   • Nivel 2: 2 enemigos en el centro de la pirámide
   • Nivel 3: 3 enemigos distribuidos en la fortaleza
   • Aleatorio: Sigue siendo aleatorio

   CÓDIGO:
   ```dart
   switch (currentLevel) {
     case GameLevel.level1:
       enemyPositions = [
         Vector2(..., -5),  // Dentro de la caja
         Vector2(..., -5),
       ];
     // ... etc
   }
   ```

5. 📏 AJUSTES DE FÍSICA
   ─────────────────────

   TAMAÑOS DE BLOQUES USADOS:
   • size70x70: Bloques pequeños cuadrados
   • size70x140: Columnas verticales
   • size140x70: Vigas horizontales
   • size220x70: Plataformas grandes

   MATERIALES POR NIVEL:
   • Nivel 1: Madera + Vidrio (ligeros)
   • Nivel 2: Madera + Vidrio + Piedra (medio)
   • Nivel 3: Madera + Vidrio + Piedra + Metal (pesado)

   POSICIONAMIENTO:
   • Y negativo = altura (más negativo = más alto)
   • X centrado en camera.visibleWorldRect.right / 3
   • Espaciado correcto para estabilidad
