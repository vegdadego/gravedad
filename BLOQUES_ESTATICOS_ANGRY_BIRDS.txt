📝 CAMBIOS TÉCNICOS:

   1. CLASE BRICK MEJORADA:
      ━━━━━━━━━━━━━━━━━━━━━━

   ANTES:
   ```dart
   class Brick extends BodyComponentWithUserData {
     Brick(...) : super(
       bodyDef: BodyDef()
         ..type = BodyType.dynamic,  // ❌ Siempre dinámico
     );
   }
   ```

   AHORA:
   ```dart
   class Brick extends BodyComponentWithUserData 
       with ContactCallbacks {  // ← Detecta colisiones
     
     final bool isStatic;  // ← Nueva propiedad
     
     Brick({
       ...
       this.isStatic = false,
     }) : super(
       bodyDef: BodyDef()
         ..type = isStatic 
             ? BodyType.static   // ✅ Congelado
             : BodyType.dynamic, // ✅ Normal
     );
     
     @override
     void beginContact(Object other, Contact contact) {
       // Si está congelado y recibe impacto...
       if (body.bodyType == BodyType.static) {
         final velocity = calcularVelocidad();
         
         // Activar si el impacto es fuerte
         if (velocity > 5) {
           body.setType(BodyType.dynamic);  // ✅ ¡ACTIVAR!
         }
       }
     }
   }
   ```

   ───────────────────────────────────────────

   2. NIVELES PREDEFINIDOS CON BLOQUES ESTÁTICOS:

⚡ VELOCIDAD DE ACTIVACIÓN:
   ────────────────────────

   UMBRAL: velocity > 5

   EJEMPLOS:
   • Alien disparado a alta velocidad:  ✅ velocity = 30-50
   • Bloque cayendo sobre otro:        ✅ velocity = 10-20
   • Toque suave:                       ❌ velocity = 2-3
   • Sin contacto:                      ❌ velocity = 0

   AJUSTABLE:
   Si quieres que se activen más fácil → velocity > 3
   Si quieres más difícil → velocity > 10
